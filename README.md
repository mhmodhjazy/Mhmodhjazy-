# Mhmodhjazy-
أنشئ تطبيق Android فاخر باسم MAHMOUD PERFUMES لابتكار العطور من وصف الرائحة. يحلل الوصف ويقترح نوتات وزيوت ومواد خام بأرقام ثابتة، مع تركيبات دقيقة بالنسب والملليلتر والغرام، وتركيز متغير وأحجام مختلفة. أضف موسوعة للعطور العالمية، وقاعدة بيانات للزيوت، ومنع تكرار النوتات، وحفظ التركيبات وتعديلها. واجهة عربية وإنجليزية.
